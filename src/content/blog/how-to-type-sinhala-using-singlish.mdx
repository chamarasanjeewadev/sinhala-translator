# How to Type Sinhala Using English Letters (Singlish): A Complete Guide

Most of us learned to type on an English keyboard, yet we think and chat in Sinhala. That is why "Singlish" — writing Sinhala words in English letters, like *oyaata kohomadha?* — is how so many Sri Lankans message each other every day. The problem starts when you need real Sinhala script: a Facebook post, a school assignment, a notice, a poster or a CV. This guide shows how to turn the way you already type into proper Sinhala Unicode, for free and without installing anything.

If you just want to start typing, open the free [Singlish to Sinhala typing tool](/singlish-to-sinhala) and come back here when you need a tip.

## What is Singlish typing?

Singlish typing (also called phonetic Sinhala typing) lets you type a Sinhala word by its sound. You type `mama gedhara yanavaa` and the tool writes **මම ගෙදර යනවා**. You do not need to learn the Wijesekara keyboard layout or memorise where each letter sits.

The text you get is **Sinhala Unicode** — the standard used by Facebook, WhatsApp, Gmail, Microsoft Word, Google Docs and every modern website. You can copy it anywhere and it displays correctly without a special font.

## The basic rules

Once you know a handful of rules, you can type almost any word.

### 1. A consonant alone gets a hal kirima

Type `k` and you get **ක්**. Add a vowel to complete the letter: `ka` → **ක**, `kaa` → **කා**, `ki` → **කි**, `ku` → **කු**, `ke` → **කෙ**, `ko` → **කො**.

### 2. Double the vowel to make it long

`a` → අ, `aa` → ආ, `i` → ඉ, `ii` → ඊ, `u` → උ, `uu` → ඌ, `e` → එ, `ee` → ඒ, `o` → ඔ, `oo` → ඕ. For **ඇ** and **ඈ** type `A` and `AA` (or `ae` and `aae`).

### 3. "th" and "dh" are the soft sounds

This is the rule most people get wrong at first:

- `th` → **ත** (as in *thaaththaa* → තාත්තා)
- `dh` → **ද** (as in *dhuva* → දුව)
- `t` → **ට** (as in *tikak* → ටිකක්)
- `d` → **ඩ** (as in *daeli* → ඩැලි)

### 4. Capital letters for the "heavier" letters

- `N` → **ණ**, `L` → **ළ**
- `sh` → **ශ**, `Sh` → **ෂ**
- `kh`, `gh`, `bh`, `ph` → **ඛ ඝ භ ඵ**

### 5. Special letters

- `x` → **ං** (`laxkaava` → ලංකාව)
- `zg` → **ඟ**, `zdh` → **ඳ**, `zd` → **ඬ**, `zb` → **ඹ**
- `gn` → **ඥ**
- `kra` → **ක්‍ර**, `kya` → **ක්‍ය**, `shrii` → **ශ්‍රී**

## Fixing mistakes while you type

In the HelaVoice tool, the word you are typing stays "live" until you press space. If you type `gedhera` by mistake, press Backspace twice and type `ara` — Backspace removes English letters, not half-built Sinhala characters. A small strip under the editor always shows the English spelling and the Sinhala result, so you can see exactly what is happening.

## Typing Sinhala by voice

If typing is slow, press **Speak** and talk in Sinhala. Voice typing uses your browser's built-in speech recognition and works best in Google Chrome and Microsoft Edge. It is ideal for a few sentences at a time.

For longer audio — interviews, lectures, meetings or WhatsApp voice notes — use [HelaVoice Sinhala voice to text](/blog/sinhala-voice-to-text), which is built for accuracy on long recordings and lets you edit and export the result.

## Unicode vs FM Abhaya (legacy fonts)

Many designers still use **FM Abhaya**, **FM Malithi** and similar legacy fonts in Photoshop and Illustrator, because older design software does not shape Sinhala Unicode correctly. Legacy fonts store Sinhala as English characters that only look right with that specific font.

The typing tool converts your Unicode text to FM Abhaya automatically. Open **FM Abhaya (legacy font)** under *Other formats*, copy the text, paste it into your design and set the font to FM Abhaya.

Use Unicode for anything online or shared. Use FM Abhaya only for design files that require it.

## Sinhala back to Singlish

Sometimes you need the reverse — a Sinhala name written in English letters, or a caption for friends who cannot read Sinhala script. The **Sinhala → Singlish** tab converts any Sinhala Unicode text into readable English letters (ලංකාව → *lankaava*).
